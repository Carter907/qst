## qst tour create

Create a new tour in manifest.yaml

```
qst tour create [tour-name] [flags]
```

### Examples

```
# Create a new tour
qst tour create "Core Fundamentals" -d my_graph/
```

### Options

```
  -h, --help   help for create
```

### Options inherited from parent commands

```
  -d, --dir string   Knowledge graph directory (default ".")
```
