## qst tour

Manage curriculum tours in the knowledge graph

### Synopsis

Tour provides commands to create, list, modify, and delete curriculum tours
configured in manifest.yaml. Tours guide readers through sequential learning paths.

### Options

```
  -d, --dir string   Knowledge graph directory (default ".")
  -h, --help         help for tour
```
