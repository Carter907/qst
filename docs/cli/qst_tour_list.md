## qst tour list

List all tours and their guide sequences

```
qst tour list [flags]
```

### Examples

```
# List all tours in current directory
qst tour list

# List tours in specific directory
qst tour list -d examples/Conditionals
```

### Options

```
  -h, --help   help for list
```

### Options inherited from parent commands

```
  -d, --dir string   Knowledge graph directory (default ".")
```
