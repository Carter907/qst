## qst tag

Manage taxonomy tags on guides in the knowledge graph

### Synopsis

Tag provides commands to list, add, and remove tags from guides' frontmatter.

### Options

```
  -d, --dir string   Knowledge graph directory (default ".")
  -h, --help         help for tag
```
