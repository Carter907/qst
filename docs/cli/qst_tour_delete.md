## qst tour delete

Delete an entire tour from manifest.yaml

```
qst tour delete [tour-name] [flags]
```

### Examples

```
# Delete a tour
qst tour delete "Core Fundamentals" -d my_graph/
```

### Options

```
  -h, --help   help for delete
```

### Options inherited from parent commands

```
  -d, --dir string   Knowledge graph directory (default ".")
```
