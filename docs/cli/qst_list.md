## qst list

List guides in the knowledge graph

```
qst list [directory] [flags]
```

### Options

```
  -d, --dir string     Knowledge graph directory (default ".")
  -h, --help           help for list
      --scope string   Filter by scope
      --tags strings   Filter by tags (comma separated)
```
