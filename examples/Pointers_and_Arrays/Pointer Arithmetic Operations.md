## Pointer Arithmetic Operations

C allows pointers to be systematically shifted across memory through **Pointer Offset Arithmetic**, scaling byte offsets based on the target type automatically.

Furthermore, algorithms can measure distance and boundary relationships across array buffers using **Pointer Comparison and Subtraction**.
