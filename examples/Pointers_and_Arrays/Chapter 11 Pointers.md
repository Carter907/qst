## Chapter 11: Pointers

This chapter introduces C's most powerful feature, beginning with **Fundamentals of Pointers** to establish the memory address model and variable declaration mechanics.

Next, it explores practical syntax through **Pointer Operators and Assignment**, covering address-of (`&`), indirection (`*`), and pointer variable assignment rules.

Finally, it connects pointers to program architecture in **Pointers in Functions**, illustrating pass-by-reference argument modification, `const` parameter safeguards, and pointer return semantics.
