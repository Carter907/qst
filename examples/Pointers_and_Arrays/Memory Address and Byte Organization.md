## Memory Address and Byte Organization

In modern computer architectures, every allocated variable has a **Memory Address** identifying its starting byte in system RAM.

The underlying physical storage is partitioned into sequential **Byte** units, each capable of holding 8 bits of program instructions or numeric data.
