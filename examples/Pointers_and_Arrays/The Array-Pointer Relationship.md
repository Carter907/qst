## The Array-Pointer Relationship

The deep harmony between arrays and pointers begins with **Array Decay to Pointer**, which treats bare array names as references to their first constituent element.

This foundational relationship powers **Subscript and Pointer Equivalence**, ensuring bracketed indexing syntax is fully interchangeable with pointer arithmetic expressions.

Consequently, function interfaces exploit this interchangeability via **Array Parameters as Pointers**, accepting either format with identical runtime efficiency.
