## String Fundamentals and Memory Layout

Understanding C strings begins with **String Storage and Representation**, where character sequences are terminated by null sentinel bytes and string literals reside in protected read-only memory regions.

Building on this storage model, **Declaring and Initializing Strings** establishes how mutable character arrays are configured on the stack and highlights the critical distinction between array buffers and pointer variables.
