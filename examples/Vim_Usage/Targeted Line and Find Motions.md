## Targeted Line and Find Motions

Horizontal character targeting is elevated by **In-Line Character Search**, finding specific punctuation and letter targets on the current line.

Macro-level vertical relocation across file coordinates is achieved via **Line Number Navigation**, targeting absolute line numbers or document limits.

Navigating code structures is simplified with **Bracket and Delimiter Matching**, jumping back and forth across enclosing programming delimiters.
