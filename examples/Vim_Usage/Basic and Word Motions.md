## Basic and Word Motions

Foundational navigation begins with home-row directional movement using **Character Motions hjkl**, anchoring hand stability across all editing sessions.

Stepping forward across linguistic boundaries is accelerated through **Word and WORD Navigation**, contrasting identifier scanning with whitespace-delimited block jumps.

Intra-line horizontal traversal relies on **Line Start and End Motions** to reach column boundaries and non-blank code edges instantly.

Vertical and viewport-level displacement is streamlined using **Screen and Scrolling Navigation** to manipulate screen placement without tedious cursor stepping.
