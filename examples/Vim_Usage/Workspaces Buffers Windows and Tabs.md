## Workspaces Buffers Windows and Tabs

Managing multiple active files in memory is accomplished via **Buffer Management**, organizing documents independently of layout.

Simultaneous multi-file viewing is enabled through **Split Window Navigation**, tiling vertical and horizontal viewports across the screen.

Grouping window layouts into distinct task-specific screens is organized through **Tab Pages**, establishing independent window workspaces.
