# Automated CLI Markdown Documentation Generator

To guarantee that CLI reference documentation in `docs/cli/` never drifts from the actual flags, examples, and command synopses implemented in `cmd/`, `internal/tools/docgen/main.go` provides a multi-format documentation compiler built on `github.com/spf13/cobra/doc`.

## Deterministic Output Generation (`docgen`)

```go
root := cmd.RootCommand()
root.InitDefaultHelpCmd()
root.DisableAutoGenTag = true
```

1. **`InitDefaultHelpCmd()`**: Initializes Cobra's built-in `help` subcommand prior to walking the command tree so `qst_help.md` is consistently included in the generated reference set.
2. **`DisableAutoGenTag = true`**: By default, `cobra/doc` stamps every generated file with a date footer (`Auto generated by spf13/cobra on DD-Mon-YYYY`). Disabling this tag ensures generated Markdown files are 100% deterministic across days and machines.
3. **Multi-Format Support**: Supports `--format markdown|man|yaml|rest`, compiling `docs/cli/qst*.md` for GitHub browsing as well as UNIX `man` pages (`GenManTree`).

## Continuous Integration Parity Gate

In `.github/workflows/go.yml` and the pre-push pipeline, `docgen` is executed followed immediately by:

```bash
go run ./internal/tools/docgen -out ./docs/cli -format markdown
git diff --exit-code docs/cli/
```

Any modification to a command's `Use`, `Short`, `Long`, `Example`, or `Flags()` in `cmd/` that is not accompanied by regenerated `docs/cli/` files fails the CI build immediately.
